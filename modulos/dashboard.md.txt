# PRD — Módulo Dashboard

## Projeto

**Nome:** Adega Cloud

**Módulo:** Dashboard

**Versão:** 1.0

---

# Objetivo

Desenvolver o Dashboard principal do Adega Cloud, fornecendo uma visão geral do negócio em tempo real, com indicadores financeiros, estoque, vendas e alertas operacionais.

O Dashboard será a primeira tela exibida após o login.

---

# Objetivos

- Exibir indicadores em tempo real.
- Facilitar a tomada de decisão.
- Mostrar alertas importantes.
- Centralizar informações do negócio.
- Permitir acesso rápido aos principais módulos.

# Alertas

Exibir automaticamente:

- Produtos com estoque baixo
- Produtos sem estoque
- Contas a pagar vencidas
- Contas a receber vencidas
- Caixa aberto
- Compras pendentes
- Produtos próximos do vencimento (futuro)

Cada alerta deverá possuir prioridade:

- Alta
- Média
- Baixa

---

# Atividades Recentes

Mostrar as últimas movimentações:

- Venda realizada
- Compra registrada
- Produto cadastrado
- Cliente cadastrado
- Pagamento recebido
- Conta paga
- Ajuste de estoque
- Login de usuário

Limite:

Últimos 20 registros

- Buscar indicadores

---

# Atualização

Atualizar automaticamente:

- A cada 60 segundos

Também permitir atualização manual através de botão.

---

# Performance

O Dashboard deverá:

- Carregar em até 3 segundos
- Utilizar cache quando possível
- Carregar gráficos sob demanda
- Exibir Skeleton Loading durante consultas

# Auditoria

Registrar:

- Alteração de filtros

---

# Regras de Negócio

- Todos os dados devem respeitar o company_id.
- Indicadores devem considerar apenas registros ativos.
- Valores financeiros devem ser calculados em tempo real.
- Alertas devem ser atualizados automaticamente.
- Usuários só poderão visualizar informações compatíveis com suas permissões.

---

# Critérios de Aceite

O módulo será considerado concluído quando:

- Dashboard carregar corretamente após o login.
- Todos os KPIs apresentarem dados consistentes.
- Todos os gráficos funcionarem.
- Alertas forem exibidos corretamente.
- Atividades recentes forem atualizadas.
- Filtros alterarem todos os indicadores.
- Atualização automática funcionar.
- Layout for responsivo.
- Tempo de carregamento permanecer abaixo de 3 segundos.
- Código seguir os padrões definidos no projeto.
