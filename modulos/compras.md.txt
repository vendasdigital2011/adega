# PRD — Módulo Compras

## Projeto

**Nome:** Adega Cloud

**Módulo:** Compras

**Versão:** 1.0

---

# Objetivo

Desenvolver o módulo de Compras responsável pelo gerenciamento do processo de aquisição de mercadorias, desde o pedido ao fornecedor até a entrada dos produtos no estoque e atualização do financeiro.

Todo o processo deverá manter rastreabilidade completa e integração automática com Estoque e Financeiro.

---

# Objetivos

- Registrar compras.
- Controlar pedidos de compra.
- Atualizar estoque automaticamente.
- Gerar contas a pagar.
- Manter histórico completo.
- Controlar status das compras.

# Recebimento

Ao confirmar o recebimento:

- Atualizar estoque automaticamente.
- Registrar movimentação de estoque.
- Atualizar custo do produto (conforme configuração).
- Gerar contas a pagar.
- Registrar auditoria.

---

# Cancelamento

Somente usuários autorizados poderão cancelar.

Ao cancelar:

- Estornar entrada no estoque.
- Cancelar contas a pagar vinculadas.
- Registrar auditoria.
- Alterar status para Cancelada.

A compra permanecerá registrada para histórico.

# Regras de Negócio

- Toda compra deve possuir um fornecedor.
- Toda compra deve possuir ao menos um produto.
- Produtos devem estar ativos.
- Quantidade deve ser maior que zero.
- Valor unitário deve ser maior que zero.
- O estoque somente será atualizado após o recebimento.
- O financeiro será atualizado automaticamente.
- Compras canceladas deverão estornar o estoque.
- Compras canceladas não poderão ser editadas.
