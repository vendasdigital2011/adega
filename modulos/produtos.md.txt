# PRD — Módulo Produtos

## Projeto

**Nome:** Adega Cloud

**Módulo:** Produtos

**Versão:** 1.0

---

# Objetivo

Desenvolver o módulo de Produtos responsável pelo cadastro, organização e gerenciamento de todos os itens comercializados pela empresa.

Este módulo será a base para Estoque, Compras, Vendas e Relatórios.

---

# Objetivos

- Centralizar o cadastro de produtos.
- Controlar preços e custos.
- Organizar produtos por categorias e marcas.
- Permitir pesquisa rápida.
- Facilitar integração com estoque e vendas.

---

# Funcionalidades

- Cadastrar produto
- Editar produto
- Visualizar produto
- Inativar produto
- Duplicar produto
- Pesquisar produto
- Filtrar produtos
- Importar produtos (CSV)
- Exportar produtos (Excel/PDF)
- Upload de imagens
- Impressão de etiquetas (futuro)

---

# Campos do Cadastro

## Identificação

- Código interno (SKU) *
- Código de barras (EAN/UPC)
- Nome *
- Nome curto
- Descrição

---

## Classificação

- Categoria *
- Marca
- Fornecedor principal
- Unidade de medida
- Tipo de produto

Exemplos:

- Bebida
- Gelo
- Carvão
- Petisco
- Acessório
- Outro

---

## Precificação

- Preço de custo *
- Preço de venda *
- Preço promocional
- Preço atacado
- Margem de lucro (%)

A margem poderá ser calculada automaticamente.

---

5 MB

---

# Código de Barras

Permitir:

- Leitura por scanner
- Digitação manual

Não permitir códigos duplicados.

---

# SKU

O SKU deverá ser único dentro da empresa.

Não permitir duplicidade.

---

# Produtos Ativos

Somente produtos ativos poderão:

- Ser vendidos
- Entrar em compras
- Aparecer em pesquisas padrão

Produtos inativos permanecerão no histórico.

---

# Exclusão

Produtos nunca serão excluídos fisicamente.

Utilizar:

Ativo

↓

Inativo

Caso possuam movimentações.

# Validações

Obrigatórias

- Nome
- SKU
- Categoria
- Preço de venda
- Preço de custo

Validações

- SKU único
- Código de barras único
- Valores monetários positivos
- Estoque mínimo ≥ 0
- Estoque máximo ≥ estoque mínimo

---

# Regras de Negócio

- Todo produto pertence a uma empresa.
- Todo produto deve possuir categoria.
- Todo produto deve possuir preço de venda.
- Produto inativo não poderá ser vendido.
- Alterações de preço devem ser registradas em auditoria.
- Alterações de custo devem ser registradas em auditoria.
- Não permitir duplicidade de SKU.
- Não permitir duplicidade de código de barras.
- Produtos com movimentação não poderão ser excluídos.

---

# Critérios de Aceite

O módulo será considerado concluído quando:

- Cadastro de produtos funcionar corretamente.
- Edição e inativação estiverem disponíveis.
- Pesquisa e filtros forem rápidos e precisos.
- Upload de imagem funcionar.
- Código de barras e SKU forem validados.
- Integração com estoque estiver preparada.
- Auditoria registrar todas as alterações.
- Layout for responsivo.
- Código seguir os padrões definidos no projeto.
