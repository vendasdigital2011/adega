# PRD — Módulo Estoque

## Projeto

**Nome:** Adega Cloud

**Módulo:** Estoque

**Versão:** 1.0

---

# Objetivo

Desenvolver o módulo de Estoque responsável pelo controle de entrada, saída, movimentações, inventários e saldo dos produtos.

Todo o estoque do sistema será atualizado automaticamente pelas operações de compras, vendas e ajustes manuais.

---

# Objetivos

- Controlar saldo dos produtos.
- Registrar todas as movimentações.
- Evitar divergências de estoque.
- Permitir inventários.
- Gerar alertas automáticos.
- Manter histórico completo.

---

- Divergência de inventário

Toda operação deverá ser registrada em auditoria.

# Regras de Negócio

- Toda movimentação deve atualizar o estoque.
- Nenhuma movimentação poderá ser excluída.
- Compras aumentam o estoque automaticamente.
- Vendas reduzem o estoque automaticamente.
- Cancelamento de venda devolve o estoque.
- Cancelamento de compra remove a entrada correspondente.
- Produtos inativos não poderão receber novas movimentações.
- Todo ajuste exige justificativa.
- Inventários geram histórico permanente.

---

# Validações

Obrigatórias:

- Produto
- Tipo de movimentação
- Quantidade
- Usuário

Validações:

- Quantidade maior que zero.
- Produto existente.
- Estoque suficiente para saída (quando estoque negativo estiver desabilitado).
- Motivo obrigatório para ajustes.

# Critérios de Aceite

O módulo será considerado concluído quando:

- Consulta de estoque funcionar corretamente.
- Entradas e saídas atualizarem o saldo automaticamente.
- Ajustes forem registrados com justificativa.
- Inventário comparar estoque físico e sistema.
- Histórico registrar todas as movimentações.
- Alertas de estoque funcionarem.
- Integração com compras e vendas estiver operacional.
- Auditoria registrar todas as operações.
- Layout for responsivo.
- Código seguir os padrões definidos no projeto.
