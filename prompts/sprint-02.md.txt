# SPRINT-02 — Autenticação

## Projeto

**Nome:** Adega Cloud

**Sprint:** 02

**Nome da Sprint:** Sistema de Autenticação

**Versão:** 1.0

**Duração Estimada:** 1 Sprint

---

# Objetivo

Implementar o sistema completo de autenticação utilizando Supabase Auth, garantindo segurança, persistência de sessão, proteção de rotas e carregamento das informações do usuário.

Ao final desta Sprint, apenas usuários autenticados poderão acessar o sistema.

---

# Objetivos da Sprint

- Implementar autenticação.
- Implementar login.
- Implementar logout.
- Recuperação de senha.
- Alteração de senha.
- Middleware.
- Sessão persistente.
- Proteção de rotas.
- Controle inicial de permissões.

---

# Dependências

Antes de iniciar esta Sprint, confirmar:

- Sprint 01 concluída.
- Supabase configurado.
- Layout funcionando.
- Providers criados.
- Variáveis de ambiente configuradas.

---

# Funcionalidades

## Login

Criar tela de login contendo:

- E-mail
- Senha
- Botão Entrar
- Link Esqueci minha senha

Ao autenticar:

- Criar sessão.
- Redirecionar para Dashboard.
- Registrar login na auditoria.

---

## Logout

Implementar:

- Encerramento da sessão.
- Limpeza de cache.
- Redirecionamento para Login.
- Registro de logout.

---

## Recuperação de Senha

Fluxo:

Usuário informa e-mail

↓

Recebe link

↓

Define nova senha

↓

Retorna para Login

---

## Alteração de Senha

Tela protegida.

Campos:

- Senha atual

- Confirmar senha

Registrar auditoria.

- Logout funcionar corretamente.
- Recuperação de senha estiver operacional.
- Alteração de senha funcionar.
- Middleware proteger todas as rotas.
- Sessão permanecer ativa corretamente.
- Informações do usuário forem carregadas após login.
- Auditoria registrar todos os eventos.
- Não existirem erros de autenticação.
