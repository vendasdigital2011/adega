# SPRINT-03 — Usuários e Permissões

## Projeto

**Nome:** Adega Cloud

**Sprint:** 03

**Nome da Sprint:** Usuários e Permissões

**Versão:** 1.0

**Duração Estimada:** 1 Sprint

---

# Objetivo

Desenvolver o módulo de gerenciamento de usuários, perfis e permissões do Adega Cloud, permitindo controlar quem pode acessar cada funcionalidade do sistema.

Ao final desta Sprint o sistema deverá possuir um controle de acesso baseado em perfis e permissões.

---

# Objetivos da Sprint

- Cadastro de usuários.
- Edição de usuários.
- Inativação de usuários.
- Cadastro de perfis.
- Cadastro de permissões.
- Controle de acesso.
- Auditoria.
- Integração com autenticação.

---

# Dependências

Antes de iniciar esta Sprint confirmar:

- Sprint 01 concluída.
- Sprint 02 concluída.
- Login funcionando.
- Sessão funcionando.
- Middleware funcionando.

# Regras de Negócio

- Todo usuário pertence a uma empresa.
- Todo usuário deve possuir um perfil.
- Apenas administradores podem criar usuários.
- Apenas administradores podem alterar permissões.
- Usuários inativos não poderão realizar login.
- Usuários bloqueados não poderão acessar o sistema.
- Um usuário não poderá remover sua própria permissão de administrador.
- Exclusão física de usuários não será permitida.
